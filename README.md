### Многофункциональный GUI Калькулятор на Python

Простой, красивый и удобный графический калькулятор, написанный на языке Python с использованием стандартной библиотеки **Tkinter**. Программа поддерживает ввод длинных математических выражений, автоматически соблюдает правильный порядок арифметических действий и обрабатывает возможные ошибки ввода. 

### ✨ Особенности

* **Цепочные вычисления:** Возможность складывать и вычислять длинные выражения в одну строку (например, 2+2+3+19-5*2).
* **Приоритет операций:** Поддержка круглых скобок ( и ) для изменения порядка вычислений.
* **Удобное управление:** Присутствуют кнопки очистки экрана (C) и удаления последнего введенного символа (⌫).
* **Красивый интерфейс:** Кнопки разделены по цветам (цифры, операции, сброс и равно) для лучшей читаемости.
* **Обработка ошибок:** Защита от вылета программы при делении на ноль или вводе некорректных символов (выводится аккуратное предупреждение).
* **Автоматическое форматирование:** Если результат вычислений является целым числом, калькулятор автоматически уберет лишнюю точку и ноль на конце (например, вместо 5.0 покажет 5).

### 🚀 Требования к системе

Для запуска программы вам понадобится только **Python 3.x**.
Никаких дополнительных библиотек устанавливать не нужно, так как tkinter встроен в стандартный набор Python. 

### 🛠️ Инструкция по запуску

1. Убедитесь, что у вас установлен Python. Проверить это можно в терминале/командной строке: 

bash

python --version

Используйте код с осторожностью.
2. Сохраните код калькулятора в файл с именем calculator.py.
3. Откройте терминал в папке с файлом и запустите его: 

bash

python calculator.py

Используйте код с осторожностью.

*(Или просто дважды кликните по файлу calculator.py мышкой).*

### 📖 Как пользоваться

1. Нажимайте на кнопки интерфейса с помощью мыши, чтобы составить пример.
2. Используйте кнопки ( и ), если нужно сначала выполнить сложение/вычитание, а затем умножение.
3. Нажмите кнопку **=** для получения результата.
4. Если вы ошиблись в последнем знаке, нажмите **⌫**. Для полной очистки экрана нажмите **C**.
